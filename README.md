# Quadruped Object Detection

Проект для управления квадроподом и автономного обнаружения целевых объектов в симуляционной среде с использованием **ROS 2**, **Isaac Gym**, RGB-D камеры и алгоритмов компьютерного зрения.

Проект разделён на две основные части:

* [`ROS2_Setup_and_Simulation`](./ROS2_Setup_and_Simulation) — подготовка окружения, запуск симуляции и интеграция Isaac Gym с ROS 2.
* [`motion_logic_and_detection`](./motion_logic_and_detection) — основная логика движения робота, обнаружения объектов и навигации по полигону.

## Структура проекта

```text
Quadruped-object-detection/
│

│   ├── Docker-конфигурации

│
└── motion_logic_and_detection/

    └── cv/
        └── модуль обнаружения объектов
```

## ROS2_Setup_and_Simulation

Данная директория предназначена для **подготовки и запуска рабочего окружения** проекта.

Несмотря на название, здесь находятся не только инструкции по установке ROS2. Директория содержит конфигурацию симуляционного окружения на базе **Isaac Gym**, Docker-образы и скрипты запуска, а также **ROS 2 bridge**, обеспечивающий обмен данными между симуляцией и ROS 2.

Поддерживаются несколько вариантов работы:

1. запуск контроллера непосредственно в Docker без ROS2;
2. запуск симуляции совместно с ROS2 Jazzy и bridge;
3. запуск Isaac Gym непосредственно на хост-системе с использованием ROS2 bridge в Docker.

Bridge обеспечивает передачу между симуляцией и ROS 2 команд движения, RGB-изображения, depth-данных, состояния суставов, скорости корпуса и данных IMU.

Основные ROS2 топики:

```text
/cmd_vel
/aliengo/base_velocity
/aliengo/camera/color/image_raw
/aliengo/camera/depth/image_raw
/aliengo/joint_states
/aliengo/imu
```

Таким образом, эта директория отвечает прежде всего за **инфраструктуру проекта: симуляцию, ROS2 и взаимодействие между ними**.

## motion_logic_and_detection

Данная директория содержит **основную пользовательскую логику автономного поведения квадропода**.

Главным компонентом является ROS 2-нода `controller.py`. Она получает данные от сенсоров робота и на их основе формирует команды движения через топик:

```text
/cmd_vel
```

Контроллер работает с несколькими источниками информации:

* RGB-изображение фронтальной камеры;
* depth-изображение;
* данные IMU;
* скорость корпуса робота;
* положения и скорости суставов.
